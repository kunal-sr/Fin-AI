## ✨ Overview

**FinanceMe** is a modern AI-powered finance management web application built using the **MERN Stack**. It helps users manage income, expenses, transactions, and financial insights in a clean and interactive dashboard.

The project focuses on:

* 📊 Smart expense tracking
* 💰 Income & transaction management
* 🤖 AI-based financial analysis
* 🔐 Secure authentication system
* 📈 Beautiful dashboard analytics
* ⚡ Fast and responsive UI

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/FinanceMe.git
cd FinanceMe
```

---

## 2️⃣ Backend Setup

```bash
cd backend
npm install
```

### ▶️ Run Backend Server

```bash
npm start
```

Backend will run on:

```bash
http://localhost:5000
```

---

## 3️⃣ Frontend Setup

```bash
cd financeMe
npm install
```

### ▶️ Run Frontend

```bash
npm run dev
```

Frontend will run on:

```bash
http://localhost:5173
```

---

# 🔐 Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
